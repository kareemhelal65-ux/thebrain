# Cortex OS — Brand Kit

This document defines the official "Intelligence Built on Structure" aesthetic for Cortex OS.

## 1. Brand Colors
To support the stark, structural typography, the color palette is heavily monochromatic and editorial, relying on extreme contrast rather than bright neon colors.

- **Primary Background:** Pure White (`#ffffff`)
- **Primary Text & Accents:** Pure Black (`#000000`)
- **Secondary / Subtitles:** Slate Gray (`#4b5563`)
- **Subtle Borders & Lines:** Light Gray (`#e5e7eb`) — used for structural dividers.

*Design Rule:* Color is removed wherever possible. Visual hierarchy is established entirely through font weight, size, and whitespace.

## 2. Typography
The typography juxtaposes heavy, dominant sans-serifs with technical monospaced fonts.

### Primary Title & Headings
- **Font Family:** Arial, sans-serif
- **Weight:** Bold
- **Color:** `#000000` (Black)
- **Tracking/Spacing:** Tightly tracked (negative letter spacing, e.g., `-4px` on massive text).
- **Usage:** Main titles, hero sections, dominant statements (e.g., "Cortex OS").

### Subtitles & Technical Data
- **Font Family:** Courier New, monospace
- **Weight:** Bold (or Regular depending on scale)
- **Color:** `#4b5563` (Slate Gray)
- **Tracking/Spacing:** Extremely wide tracking (positive letter spacing, e.g., `8px`).
- **Usage:** Subtitles (e.g., "INTELLIGENCE BUILT ON STRUCTURE"), system outputs, metadata, code blocks.
